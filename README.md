# ReleaseReady

Notes on shipping **Expo & React Native apps** — release engineering, CI, build gates, and the
store-submission grind. *A Boolean Bros project.*

Static site served via GitHub Pages.

## Writing a post
Add an HTML file under `posts/`, then link it from `index.html`. Keep it plain HTML + `style.css`
(no build step).

## Local preview
Open `index.html` directly, or run any static server.
