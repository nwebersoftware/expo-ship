# OWNED DISTRIBUTION — the long game (plan)

**Bet:** with a multi-year horizon and no audience, optimize for the asset that compounds —
**owned distribution** (SEO footprint + open-source/audience) — and monetize it with products the
AI factory produces. Products don't compound; distribution does.

**Topic (narrow + permanent):** *shipping React Native / Expo apps to the stores* — release
engineering, CI, build gates, and the store-submission grind. This is Nate's real, rare expertise
and it stays relevant for years.

## Why this and not marketplaces
- Envato/CodeCanyon: **closed** to new authors. Creative Market: design-only, curated. Gumroad: no
  discovery. → We can't rent discovery. We build it.
- Owned channels (Google + GitHub) need **no permission** and get *more* valuable each year.

## The flywheel
```
free useful stuff (OSS tools + write-ups)
        ↓  Google + GitHub traffic
   newsletter / audience (email = the moat)
        ↓
   products (templates/apps from the factory)
        ↓  revenue funds more free stuff
```

## Assets to build (in order)
1. **Blog base** — static site on GitHub Pages (`nwebersoftware.github.io`), fast, no lock-in.
2. **First article** — "Two build gates that make RN quality non-negotiable" (already written).
3. **First OSS tool** — a small, genuinely useful Expo/RN utility (NOT duplicating `expo-doctor`;
   candidate: store-listing ↔ app consistency / release-readiness checks for the *store* gate).
4. **Cadence** — publish ~2×/month forever. Slow, compounding.

## 90-day plan
- **Weeks 1–2:** site live; publish article #1; set up an email capture (free tier).
- **Weeks 3–6:** ship OSS tool #1; write the "how it works" post + README.
- **Weeks 7–12:** 4 more posts (each solving one concrete shipping problem); submit OSS tool to
  relevant awesome-lists once it has traction; add a product CTA to the best-performing posts.

## Metrics that matter
Google impressions/clicks (Search Console), GitHub stars/clones, email subscribers — **not** sales
(at first). Sales are a lagging indicator of distribution.

## Honest risk
This is slow by design (SEO = months). The value is that it's *durable* and *ours*; it re-opens every
other channel (marketplaces, partnerships) as it grows. If we want revenue sooner, we layer products
on top as traffic appears.
